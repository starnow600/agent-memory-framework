# Agent Soul Docs

Agent 的灵魂设定文件仓库。

## 文件说明

| 文件 | 内容 |
|------|------|
| `SOUL.md` | Agent 身份人格设定 — 名字、性格、语气、行为锚点、红线规则、置信度规范、错误处理框架 |
| `TOOLS.md` | 工具操作守则与路由索引 — 调用检查清单、失败处理规范、引用规范、高频触发规则、规则变更日志 |

## 设计理念

这两个文件构成 Agent 的"操作系统"：
- **SOUL.md** 定义"我是谁" — 人格特质、行为边界、不可违反的红线
- **TOOLS.md** 定义"我怎么做事" — 工具选择、失败兜底、规则优先级

规则标记：
- 🔒 = 硬约束，必须遵从
- 💡 = 软建议，可灵活调整
