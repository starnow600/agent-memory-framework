# Functional: 市场状态快速判断（Regime Check）

## 触发条件
需要快速判断当前市场整体状态（牛市/熊市/震荡）、市场情绪、板块轮动方向时

## 功能定位
组合调用iFinD index-mcp + news-mcp模块，从指数趋势、板块热度、市场情绪三个维度交叉验证市场状态。

## 标准流程

### Step 1: 核心指数趋势判断（index_data）
用 `mcp__hexin-ifind-ds-index-mcp__index_data` 查询核心指数技术面：
- **指数清单**: 上证指数(000001.SH) + 深证成指(399001.SZ) + 创业板指(399006.SZ) + 沪深300(000300.SH)
- **指标**: 近20日涨跌幅 + MA20趋势 + 近期高低点
- **日期格式**: `YYYYMMDD-YYYYMMDD`
- **判断**: 指数在MA20上方=偏多，下方=偏空；多个指数一致=信号更强

### Step 2: 板块热度扫描（sector_data）
用 `mcp__hexin-ifind-ds-index-mcp__sector_data` 查询主要行业板块表现：
- **板块清单**: 电子、计算机、医药生物、电力设备、有色金属、汽车、食品饮料（核心行业轮动观察池）
- **指标**: 近5日+近20日涨跌幅 + 成交额变化
- **判断**: 哪些板块领涨/领跌、是否有持续性、资金流向方向

### Step 3: 市场情绪指标（index_highfreq_quotes实时模式）
用 `mcp__hexin-ifind-ds-index-mcp__index_highfreq_quotes` 实时模式获取情绪数据：
- **指数**: 上证指数 + 深证成指
- **指标**: 上涨家数/下跌家数/涨停家数/跌停家数/振幅
- **判断**: 涨跌家数比、涨跌停对比，判断市场赚钱效应

### Step 4: 热门事件验证（search_trending_news）
用 `mcp__hexin-ifind-ds-news-mcp__search_trending_news` 查近期热门：
- **时间范围**: 近一周 或 24小时（看需求）
- **关键词**: 可选，用于聚焦特定主题
- **判断**: 是否有重大政策/事件驱动当前市场走势

### Step 5: 综合判断
将以上4个维度的结果汇总，得出市场Regime结论：
- **BULL（牛市）**: 多数指数在MA20上方 + 板块普涨 + 涨多跌少 + 有正向催化
- **BEAR（熊市）**: 多数指数在MA20下方 + 板块普跌 + 跌多涨少 + 有负向催化
- **NEUTRAL（震荡）**: 指数在MA20附近 + 板块分化 + 涨跌各半 + 无明确催化

## 依赖的原子补丁
- atom-ifind-index-sector（Step 1/2/3）
- atom-ifind-news-notice（Step 4）

## 输出结构
1. 指数趋势概览（表格）
2. 板块热度排名（涨跌幅排序）
3. 市场情绪指标（涨跌家数/涨跌停）
4. 近期催化事件
5. Regime结论 + 置信度（高/中/低）

## 反模式
- ❌ 只看一个指数就下结论（指数分化时容易误判）
- ❌ 只看技术面不看事件驱动（市场走势背后有原因）
- ❌ 日内波动就改判断（Regime是中期状态，不是日频切换）
- ❌ 忽略板块结构（指数涨但个股跌，或反之，要看内部结构）

## 适用边界
- 适用: A股整体市场状态判断、板块轮动分析、市场情绪监测
- 不适用: 个股分析、境外市场判断、精确的择时信号
- 参考: func-regime-adapt / func-regime-switch-3day-confirm
