# Functional: 持仓评分与动作映射

## 触发条件
持仓评分计算

## 操作模式
4因子加权：
- 趋势强度 35%
- 波动率适配 22.5%
- 信号衰减 17.5%
- 技术结构 25%

动作阈值：
| 分数 | 动作 |
|------|------|
| 80-100 | 满仓持有 |
| 60-80 | 持有 |
| 40-60 | 减仓 |
| 20-40 | 清仓 |
| 0-20 | 强制清仓 |

## 反模式
- ❌ 用建仓评分替代持仓评分（两者逻辑不同）
- ❌ 1手持仓忽略整手约束（1手=100股，无法减半仓，只有持有/清仓两个选项）
- ❌ 持仓天数用自然日而非K线交易日计数（6/19端午教训）
