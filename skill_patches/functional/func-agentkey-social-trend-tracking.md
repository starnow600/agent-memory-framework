# Functional: AgentKey社媒趋势追踪流程

## 触发条件
需要追踪某个话题/品牌/事件在多个社媒平台的传播热度、用户反馈、内容趋势时；营销监测、舆情追踪、内容创作素材搜集

## 功能定位
组合调用 AgentKey 社媒类多个平台工具，跨平台追踪话题热度，对比各平台传播差异，提取热点内容和关键观点。

## 标准流程

### Phase 1: 确定追踪关键词与平台选择
- **关键词定义**：
  - 核心关键词（1-3个）：话题的核心表达
  - 扩展关键词（2-5个）：同义词、相关词、品牌名/产品名变体
  - 排除词（可选）：避免噪音的排除词
- **平台选择**：根据话题属性选择目标平台（不要27个平台全上）
  - 消费/品牌/美妆 → 小红书 + 抖音 + 微博
  - 科技/数码/游戏 → B站 + 知乎 + 微博
  - 舆情/社会事件 → 微博 + 抖音 + 知乎
  - 海外话题 → Twitter + TikTok + Reddit
- **产出**：关键词清单 + 目标平台列表 + 追踪时间范围

### Phase 2: 多平台热度探测（快速扫描）
在选定的平台上分别搜索关键词，获取各平台热度概况。

- **各平台搜索**：
  - 用各平台的搜索工具查询关键词
  - 获取：相关帖子/视频数量、互动量概览、热门内容Top列表
  - 工具选择：优先用搜索类工具（成本低、速度快）

- **热度初步评估**：
  - 各平台内容量对比
  - 互动量级对比（点赞/评论/转发/收藏）
  - 时间分布（是突发热点还是持续讨论）
- **判断点**：
  - 哪些平台热度最高？优先深入
  - 哪些平台几乎没有讨论？可以放弃
  - 热度趋势是上升还是下降？

### Phase 3: 重点平台深度钻取
对热度最高的2-3个平台做深度数据获取。

- **内容维度**：
  - 热门内容Top N（按点赞/播放/互动排序）
  - 内容类型分布（图文/视频/评论/问答）
  - 关键KOL/账号（影响力大的发声者）

- **观点维度**：
  - 主流观点倾向（正面/负面/中性占比）
  - 核心观点聚类（主要讨论点有哪些）
  - 争议点（有分歧的话题）

- **用户维度**：
  - 参与用户画像（年龄/性别/地域，如有数据）
  - 活跃用户类型（普通用户/KOL/营销号）

### Phase 4: 热点内容提取与分析
从各平台热门内容中提取有价值的信息。

- **代表性内容**：
  - 高互动量的爆款内容
  - 观点鲜明的争议性内容
  - 专业/行业人士的深度分析

- **趋势信号识别**：
  - 新兴的讨论方向（最近突然增加的话题）
  - 意见领袖的态度变化
  - 从一个平台向另一个平台的传播迹象

### Phase 5: 综合报告输出
- 各平台热度对比
- 核心观点总结
- 热点内容精选
- 趋势判断（上升/平稳/下降）
- 风险点提示（负面舆情/争议话题）

## 依赖的原子补丁
- atom-agentkey-social-media（核心依赖，全流程使用）
- atom-agentkey-web-search（可选，补充全网搜索视角）

## 输出结构
1. 热度概览（各平台内容量/互动量对比）
2. 平台差异分析（各平台讨论重点有何不同）
3. 核心观点提炼（主流观点 + 争议点）
4. 热点内容Top 10（分平台）
5. 趋势判断与时间线
6. 风险/机会提示

## 反模式
- ❌ 27个平台全查一遍（成本高效率低，80%热度集中在2-3个平台）
- ❌ 只看数量不看质量（100个水军帖不如1个KOL真实分析）
- ❌ 一次查完就结束（趋势是动态的，需要时间维度对比）
- ❌ 不分平台用同一套分析框架（每个平台的内容生态和用户行为不同）
- ❌ 上来就拉全量数据（先用搜索类工具探测，有价值再深入）

## 成本控制策略
1. **先广后深**：先用低成本搜索类工具快速扫所有目标平台，再对热度高的平台深入
2. **平台数量控制**：一般2-3个重点平台足够，不要贪多
3. **Top N原则**：每个平台只取Top内容（如Top 20/Top 50），不要全量
4. **时间范围限定**：限定时间范围（如最近7天），不要拉历史全部数据
5. **定期vs一次性**：长期追踪用话题追踪v3，一次性深度分析用本流程

## 与话题追踪v3的关系

| 维度 | 本功能（AgentKey社媒趋势） | 话题追踪v3 |
|------|---------------------------|------------|
| 定位 | 一次性深度钻取 | 长期定期追踪 |
| 数据来源 | 27个社媒平台结构化数据 | 全网新闻源+搜索 |
| 更新频率 | 按需执行 | 定期（每日/每周简报） |
| 分析深度 | 深（多平台细粒度数据） | 中（摘要式简报） |
| 成本 | 较高（按credits计） | 有skill运行成本 |
| 典型场景 | 营销监测、竞品分析、热点复盘 | 行业动态追踪、长期关注话题 |

**互补模式**：话题追踪v3发现热点 → AgentKey社媒趋势追踪深入钻取 → 形成深度分析

## 适用边界
- 适用：营销监测、舆情追踪、内容创作素材搜集、竞品社媒分析、热点事件复盘
- 不适用：长期定期追踪（用话题追踪v3）、简单信息查询（用web_search）、纯新闻类追踪（用话题追踪v3）
