# Functional: 多协议复合吞吐效应识别

## 触发条件
当本周期内有≥2个新协议/规则/机制同时落地时

## 操作模式
1. **识别本周期新增协议**：列出所有本周期生效的协议/规则/技能
2. **评估复合效应**：判断它们是否形成了"1+1>2"的吞吐效应
3. **区分单协议效果vs复合效果**：
   - 单协议效果：协议A独立带来的改进
   - 复合效果：协议A+B+C交互产生的额外改进
4. **记录到叙事**：显式标注"这是复合效应，非单协议功劳"
5. **预防过度归因**：复合效应可能在下一个周期衰减，需观察稳定性

## 复合效应的常见组合
- 行为锚点（SOUL.md）+ 持久化协议 + 标记体系 = 行为审计闭环
- 索引协议 + 预处理思路 + 回测驱动 = 记忆系统升级
- Implementation Notes + 决策树更新 + 蒸馏协议 = 元能力演化

## 评估方法
- 对比"仅A生效"vs"A+B生效"vs"A+B+C生效"的数据
- 区分"协议自身价值"vs"协议间协同价值"
- 警惕"草率化"风险：快速化也可能掩盖质量问题

## 反模式
- ❌ 看到"效果好"就归功于最新协议（可能与历史协议协同）
- ❌ 多个协议同时上线时无法区分各自贡献
- ❌ 把"外部条件就绪"误判为"系统能力提升"
