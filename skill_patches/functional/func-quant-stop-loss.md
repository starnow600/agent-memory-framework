# Functional: Hybrid动态止损计算

## 触发条件
计算持仓止损价

## 操作模式
- ATR止损和固定5%止损取更严格者
- 试探仓（45-54分）：2.5×ATR(14)
- 标准仓（≥55分）：3.0×ATR(14)
- Chandelier Exit = MAX(20日最高价) - 3×ATR(14)

## 止损逻辑
- Hybrid止损 = min(ATR止损, 5%固定止损)
- ATR止损防波动率差异：高波动股ATR止损宽于5%，低波动股ATR止损窄于5%
- Chandelier Exit防趋势反转阴跌，与Hybrid止损互补
- 执行止损采用5-10分钟观察窗口

## 反模式
- ❌ 只用固定百分比止损（忽略波动率差异）
