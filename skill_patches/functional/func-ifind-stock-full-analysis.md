# Functional: iFinD单只股票全景分析

## 触发条件
需要对一只A股个股进行全面分析（技术面+基本面+事件风险）时，如建仓前深度分析、持仓标的定期审查

## 功能定位
组合调用iFinD stock-mcp多个工具，形成单只股票的全景分析报告，为投资决策提供数据支撑。

## 标准流程

### Phase 1: 快速画像（1个工具）
先用 `get_stock_summary` 获取全貌摘要，判断是否值得深入分析。
- **输入**: 股票代码/简称
- **产出**: 公司基本情况+近期行情+估值水平+财务概览
- **判断点**: 行业是否在能力圈内、市值是否符合偏好、估值大致区间

### Phase 2: 技术面分析（1-2个工具）
- **日频行情+技术指标**: `get_stock_performance`
  - 查询内容: 近60日K线 + MACD/KDJ/MA等技术指标 + 近期形态（是否创新高/突破等）+ 成交量变化
  - 日期格式: `YYYYMMDD-YYYYMMDD`
- **实时行情**（如盘中）: `stock_highfreq_quotes`
  - 模式: real_time
  - 指标: 最新价/涨跌幅/成交量/换手率/市盈率TTM
- **产出**: 趋势判断、支撑阻力位、技术形态、量价配合情况

### Phase 3: 基本面分析（1-2个工具）
- **核心财务**: `get_stock_financials`
  - 查询内容: 最新报告期ROE/净利润率/资产负债率/营收增长率 + PE/PB/PS估值及分位数
- **股本股东**: `get_stock_shareholders`
  - 查询内容: 流通股占比 + 前十大股东持股比例 + 机构持股比例
- **可选-ESG**: `get_esg_data`
  - 仅在ESG投资框架下查询
- **产出**: 盈利能力、成长性、负债水平、估值高低、股东结构

### Phase 4: 事件与风险（1-2个工具）
- **重大事件**: `get_stock_events`
  - 查询内容: 近3个月重大事件（增减持/解禁/并购/监管问询/股权激励等）
- **风险指标**: `get_risk_indicators`
  - 查询内容: beta值（以沪深300为基准）+ 波动率 + VaR
- **产出**: 近期事件风险、系统性风险水平、波动率特征

### Phase 5: 新闻与公告验证（可选）
- 用 `atom-ifind-news-notice` 搜索近期新闻和公告
- 验证是否有未被结构化事件捕捉的信息

## 依赖的原子补丁
- atom-ifind-stock-summary（Phase 1）
- atom-ifind-stock-kline（Phase 2）
- atom-ifind-stock-fundamental（Phase 3）
- atom-ifind-stock-events（Phase 4）
- atom-ifind-news-notice（Phase 5，可选）

## 输出结构
1. 公司画像（一句话定位+行业+市值）
2. 技术面评估（趋势/位置/量价）
3. 基本面评估（盈利/成长/估值）
4. 事件与风险提示
5. 综合判断与关注要点

## 反模式
- ❌ 上来就查一堆数据，没有递进逻辑（先摘要→再深入）
- ❌ 只看技术面不看基本面（容易踩基本面雷）
- ❌ 忽略事件风险（解禁/减持/监管问询都是催化剂）
- ❌ 所有股票都用同一套查询（轻仓试探标的不需要全流程）

## 适用边界
- 适用: A股个股深度分析（建仓前/定期审查/事件驱动）
- 不适用: 批量全市场扫描（用量化引擎）、指数/板块分析、基金分析
