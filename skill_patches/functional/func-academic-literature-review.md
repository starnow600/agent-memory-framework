# Functional: 学术文献综述标准流程

## 触发条件
需要对某个学术/医学主题进行文献综述时，如研究某疾病治疗进展、某技术发展趋势、某药物临床数据

## 功能定位
组合PubMed + Semantic Scholar双源检索，交叉验证，确保文献覆盖的全面性和权威性。

## 标准流程

### Phase 0: 主题定义与检索策略
- 明确综述目标（最新进展/争议问题/方法学比较/临床证据等级）
- 确定关键词：主关键词 + 同义词 + MeSH术语（医学主题）
- 设定时间范围：近5年（常规）/ 近10年（发展趋势）/ 全部（经典回顾）
- 文献类型：综述优先（快速了解全貌）→ 原始研究（深入细节）

### Phase 1: PubMed检索（医学主题核心源）
使用 `atom-pubmed-medical-search`：
1. **初步检索**: 主关键词检索，看文献总量和分布
2. **综述筛选**: 过滤Review类型，快速建立知识框架
3. **临床试验筛选**: 如关注临床证据，过滤Clinical Trial类型
4. **高引经典**: 按被引或时间排序，标记必看文献
5. **产出**: 核心文献列表（PMID列表+摘要笔记）

### Phase 2: Semantic Scholar补充（全学科+引用网络）
使用 `atom-semantic-scholar-paper-search`：
1. **同关键词检索**: 与Phase 1相同关键词，补充PubMed未覆盖的
2. **引用网络扩展**:
   - 对Phase 1的核心论文，查其引用的文献（往前追溯基础）
   - 查引用这些核心论文的新论文（往后追踪进展）
3. **作者追踪**: 找到领域内核心研究者，看其最新工作
4. **学科交叉**: 如果主题涉及多学科（如AI+医学），补充计算机科学等领域的文献
5. **产出**: 补充文献列表 + 引用关系图谱（文字描述）

### Phase 3: 交叉验证与去重
- 对比两个来源的结果，标记共同出现的高相关文献（双源命中=重要性更高）
- 去重（同一篇论文可能在两个数据库都有）
- 按重要性分级：
  - ⭐⭐⭐ 双源高引 + 领域经典
  - ⭐⭐ 单源高引 + 近期发表
  - ⭐ 边缘相关 + 补充阅读

### Phase 4: 综合与结构化输出
1. **领域概览**: 研究历史、主要流派、核心问题
2. **关键进展**: 按时间线或主题梳理重要发现
3. **争议与共识**: 领域内的主要争议点和已达成的共识
4. **未来方向**: 当前研究趋势和待解决问题
5. **核心文献清单**: 按重要性分级的文献列表（含PMID/DOI+一句话摘要）

## 依赖的原子补丁
- atom-pubmed-medical-search（Phase 1）
- atom-semantic-scholar-paper-search（Phase 2）

## 适用场景分级

| 场景 | 流程 | 预计文献量 |
|------|------|-----------|
| 快速了解（轻量） | 仅PubMed综述检索 + 5-10篇核心 | 5-10篇 |
| 标准综述 | 完整Phase 1-4 | 20-50篇 |
| 深度研究 | 完整流程 + deep-research多源验证 | 50-100+篇 |

## 反模式
- ❌ 只查一个数据库就下结论（漏检风险）
- ❌ 只看综述不看原始研究（综述有作者倾向，可能选择性引用）
- ❌ 只看中文文献（顶级研究大多是英文）
- ❌ 贪多不求精（几百篇文献看不完，先聚焦核心再扩展）
- ❌ 把摘要当全文（摘要信息有限，关键数据和方法可能在正文里）

## 适用边界
- 适用: 医学/生物医学/健康科学主题的文献综述
- 部分适用: 其他学科（PubMed不覆盖，只用Semantic Scholar即可）
- 不适用: 非学术主题（行业动态/政策/市场数据用web_search或deep-research）
