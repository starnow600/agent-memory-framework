# Atomic: 重复失败=系统性问题信号

## 触发条件
同一规则/约束被违反≥3次时

## 规则
1. **3次重复 = 系统性问题**：不是偶然失误，是流程设计缺陷
2. **必须引入completion criteria checklist**：将模糊的"做完了"变成可逐项勾选的显式清单
3. **优先级最高**：在改进排序中，解决重复失败应排在首位（最高杠杆）
4. **降级标注机制**：未完成项必须标注 `[PARTIAL: xxx]`，让遗漏无处藏身

## 反面教训
风控遗漏全量扫描在30天内重复3次（6/12、6/29、7/3），是唯一多次复现的问题。
根因：没有显式的完成标准，执行者主观认为"做了一部分=完成了"。
引入语义退出条件后，问题可避免。
