# atom-semantic-scholar-paper-search（Semantic Scholar学术论文搜索）

**层级**: Atomic
**ID**: atom-semantic-scholar-paper-search
**触发**: 需要搜索学术论文、查询论文详情与引用网络、获取作者信息及论文列表时
**来源**: Semantic Scholar技能新装（semantic-scholar::7639944496733618195），2026-09-12

---

## 工具能力概述

Semantic Scholar 学术论文知识图谱查询工具，覆盖2亿+学术论文：

| 能力 | 说明 |
|------|------|
| 学术论文搜索 | 按关键词/主题搜索全学科论文 |
| 论文详情查询 | 获取单篇论文的详细信息（摘要、作者、期刊、DOI、引用量等） |
| 引用网络分析 | 查询论文的引用关系（被引/引用）、引用上下文 |
| 作者信息查询 | 获取研究者的论文列表、引用统计、研究领域 |
| 学科覆盖 | 计算机科学、生物学、医学、物理学、社会学等全学科 |

## 输入要求 / 参数规范

- **查询方式**:
  - 关键词检索：按主题/关键词搜索论文
  - 论文检索：按标题/DOI/SS ID精确查询
  - 作者检索：按作者名查询其论文列表和引用数据
- **建议**: 学术关键词用英文搜索结果更全面（中文论文也有，但英文为主）

## 输出格式说明
- 搜索结果：论文标题、作者、年份、引用量、摘要片段
- 论文详情：完整元数据 + 开放获取状态（是否可免费获取全文）
- 引用网络：引用/被引论文列表 + 引用上下文（引用该论文时的句子）

## 常见坑与避错指南

1. **引用数据可能不完整🟡**：虽然覆盖2亿+论文，但部分期刊/会议的引用数据可能有延迟或缺失
2. **作者同名问题🟡**：学术圈同名作者常见，查询作者时需结合机构、研究领域确认身份
3. **英文为主🟢**：高质量论文以英文为主，中文论文覆盖度低于知网等中文数据库
4. **获取全文🟢**：部分论文标注为"Open Access"可直接获取全文，付费论文需另外途径
5. **搜索结果排序🟢**：默认按相关性排序，高引用论文不一定排在前面

## 适用边界（什么情况不用）

- ❌ 纯医学文献深度检索 → 用 PubMed（更专业、更全面）
- ❌ 中文文献为主 → 用知网/万方或web_search
- ❌ 最新新闻/政策/行业动态 → 用web_search
- ❌ 系统综述/荟萃分析专门检索 → PubMed更精准（有专门的文献类型过滤）
- ❌ 专利检索 → 专用专利数据库或web_search

## 与同类工具的比较

| 维度 | Semantic Scholar | PubMed | web_search | Google Scholar |
|------|------------------|--------|------------|----------------|
| 覆盖学科 | 全学科 | 生物医学 | 混合 | 全学科 |
| 论文数量 | 2亿+ | 3500万+ | 不定 | 最多（不公开） |
| 引用网络 | 强（有上下文） | 弱 | 无 | 强 |
| API可用性 | 有（本skill） | 有（PubMed skill） | 间接 | 无官方API |
| 医学权威性 | 好 | 最高 | 低 | 好 |
| 中文支持 | 有少量 | 极少 | 好 | 有一些 |

## 为什么重要

Semantic Scholar的核心价值在于**引用网络**——不仅能查到论文被引了多少次，还能看到"谁在什么语境下引用了这篇论文"。这对判断一篇论文的学术影响力、追踪研究前沿、找到相关工作非常有价值。在做技术趋势研究、跨学科调研时，Semantic Scholar是比PubMed更通用的工具。
