# atom-pubmed-medical-search（PubMed医学文献搜索）

**层级**: Atomic
**ID**: atom-pubmed-medical-search
**触发**: 需要查找医学论文、获取文献摘要、查询临床试验、搜索医学研究综述时
**来源**: PubMed技能新装（pubmed-data::7641068707355131954），2026-09-12

---

## 工具能力概述

通过 NCBI E-utilities 访问 PubMed 医学文献数据库，覆盖3500万+生物医学文献：

| 能力 | 说明 |
|------|------|
| 全文搜索 | 按关键词/主题搜索PubMed文献，返回相关文献列表 |
| 批量获取文献摘要 | 获取多篇文献的摘要、作者、期刊、发表时间等信息 |
| 按PMID获取引用信息 | 根据PubMed ID精确获取单篇文献的引用信息 |
| 搜索临床试验 | 筛选临床试验类型的文献 |
| 搜索研究综述 | 筛选综述（Review）类文献 |

## 输入要求 / 参数规范

- **查询主题**: 医学/生物医学领域的关键词，建议使用医学术语（MeSH术语优先）
- **支持的检索方式**:
  - 关键词检索（如"diabetes treatment"）
  - PMID精确检索（如"PMID: 12345678"）
  - 文献类型过滤（临床试验/综述/系统评价）

## 输出格式说明
- 文献列表：标题、作者、期刊、发表年份、PMID
- 摘要详情：结构化摘要（背景/方法/结果/结论）或非结构化摘要
- 引用信息：被引用情况（需结合PMCID或其他来源）

## 常见坑与避错指南

1. **关键词专业度要求高🟡**：用普通词汇可能漏检，优先使用MeSH术语或规范医学英文术语
2. **全文不可下载🟡**：PubMed只提供摘要和元数据，获取全文需要另外的途径（期刊网站、Sci-Hub等），对应规则见atom-ima-no-download
3. **英文为主🟢**：PubMed以英文文献为主，中文医学文献覆盖有限
4. **文献数量庞大🟢**：热门关键词可能返回几万条结果，需通过时间范围、文献类型等条件缩小范围
5. **引用数据不完整🟢**：PubMed本身的引用数据不如Scopus/Web of Science全面，做引用分析建议结合Semantic Scholar

## 适用边界（什么情况不用）

- ❌ 非医学领域学术论文 → 用 Semantic Scholar（atom-semantic-scholar-paper-search）
- ❌ 引用关系深度分析 → 用 Semantic Scholar（知识图谱更完善）
- ❌ 获取论文全文PDF → PubMed不提供全文下载
- ❌ 中文医学文献 → 用知网/万方或web_search
- ❌ 药物说明书/临床指南 → 用web_search或专业数据库

## 与同类工具的比较

| 维度 | PubMed | Semantic Scholar | web_search |
|------|--------|------------------|------------|
| 覆盖领域 | 生物医学（最权威） | 全学科（2亿+论文） | 取决于关键词 |
| 数据质量 | 高（NCBI官方） | 高（AI提取+多源融合） | 中（混合来源） |
| 引用网络 | 基础 | 强（知识图谱+引用上下文） | 弱 |
| 全文获取 | 仅摘要 | 部分有开放获取全文 | 视来源而定 |
| 中文支持 | 极少 | 有少量 | 好 |

## 为什么重要

PubMed是生物医学领域最权威的文献数据库，没有之一。在做医学相关的投资研究（如医药股基本面分析、新药研发进展跟踪、疾病流行病学研究）时，PubMed提供的循证医学证据是判断的重要依据。
