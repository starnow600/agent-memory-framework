# atom-agentkey-crypto-data（AgentKey加密货币数据）

**层级**: Atomic
**ID**: atom-agentkey-crypto-data
**触发**: 需要加密货币价格行情、链上数据、交易所数据、代币分析、社交情绪、NFT数据时
**来源**: 2026-09-12_AgentKey_MCP接入，加密货币类工具实测（15大类、180+工具）

## 工具能力概述

AgentKey 加密货币类覆盖 15 大类、180+ 工具，涵盖行情、交易所、链上、DEX、代币、社交情绪、新闻、NFT、预测市场等全维度。按 credits 计费。

| 类别 | 工具数 | 核心能力 |
|------|--------|----------|
| market（行情） | ~25 | 币价/历史K线/CMC指数/全球市场数据 |
| exchange（交易所） | ~16 | 交易所行情/深度/资金费率/多空比/合约数据 |

| token（代币） | ~10 | 代币信息/持有者/转账/合约 |
| social intel（社交情绪） | ~13 | 社交情绪/关注度/热议度/恐慌贪婪 |
| news（新闻） | ~12 | 加密货币新闻/公告/快讯 |
| events（事件） | ~8 | 空投/日历/活动/解锁 |
| nft（NFT） | ~7 | NFT数据/地板价/持有者/交易量 |

| 其他 | ~30 | 域名/项目/搜索/钱包/借贷 等 |

### 调用三步法
1. `mcp__agentkey__find_tools(q="加密货币+具体需求")` 或 `prefix="crypto/"`
2. `mcp__agentkey__describe_tool(name="<工具名>")` — 查参数+成本
3. `mcp__agentkey__execute_tool(...)` — 执行

## 输入要求 / 参数规范

- 行情类：通常需要交易对（如 BTC/USDT）、时间范围
- 链上类：需要地址/交易哈希/区块号
- 代币类：需要合约地址或代币符号
- 各工具参数差异大，必须先 describe_tool 确认

## 输出格式说明
- 行情数据：价格/成交量/涨跌幅等结构化数据
- 链上数据：原始链上交易/区块数据
- 情绪数据：量化指标（如恐慌贪婪指数、社交提及量）
- 各供应商返回格式不同

## 常见坑与避错指南

1. **非主业🔴**：我们的主投资领域是A股，加密货币数据仅用于了解/研究/参考，不直接用于交易决策（用户约束：虚拟炒股只做A股）
2. **数据质量参差不齐🟡**：不同数据源质量差异大，关键数据建议交叉验证
3. **链上数据解析成本高🟡**：链上原始数据量大且复杂，按需查询，不要拉全量
4. **交易对格式🟢**：注意交易对命名规范（BTC/USDT vs BTCUSDT），不同供应商格式可能不同
5. **更新频率🟢**：加密货币7x24小时交易，数据是实时的
6. **多交易所价差🟢**：同一币种不同交易所价格有差异，注意区分

## 适用边界（什么情况不用）

- ❌ A股/港股/美股股票 → 用iFinD MCP或stock-data-skill
- ❌ 需要交易决策级别的财务/基本面数据 → 加密领域没有传统财务概念
- ❌ 只是想知道比特币价格 → web_search 就能搞定，没必要用AgentKey
- ❌ 大量链上数据分析 → 成本可能很高，先评估再执行
- ❌ 作为投资决策依据 → 我们不做加密货币投资（用户约束：只做A股）

## 为什么重要

虽然加密货币不是我们的主投资领域，但 AgentKey crypto 提供了完整的加密货币数据覆盖，在以下场景有价值：
1. 了解全球加密市场动态，辅助判断科技/风险偏好情绪
2. 研究区块链/加密行业趋势（行业研究场景）
3. NFT/链上创新追踪（前沿科技观察）
4. 预测市场数据（另类情绪指标）

核心原则：了解和研究可以，不做投资决策。
