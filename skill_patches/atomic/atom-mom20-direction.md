# Atomic: 追涨建仓MOM20必须为正

## 触发条件
追涨模式建仓信号评分≥55

## 规则
1. **MOM20>0**：追涨建仓必须MOM20>0，负值说明趋势方向根本没确立
2. **MOM5不可覆盖**：MOM5短期脉冲不可覆盖MOM20方向判断
3. **硬门槛**：这是建仓硬门槛，不是软扣分项

## 量化表达
```
建仓条件 = 评分≥55 且 MOM20>0 且 过去3日评分≥45天数≥2
```

## 反面教训

- 评分靠MOM5短期脉冲拉上来（+11.56%）
- MOM20一直是负的，趋势方向未确立
- 6/23评分就崩到36.8，一天跌21分

工业富联6/22评分67.2，MOM20=+30%以上（趋势持续几周），多空对比明显。
