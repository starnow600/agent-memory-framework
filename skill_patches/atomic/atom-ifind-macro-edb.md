# atom-ifind-macro-edb（iFinD宏观经济数据查询）

**层级**: Atomic
**ID**: atom-ifind-macro-edb
**触发**: 需要查询宏观经济指标、行业经济数据、大宗商品数据时
**来源**: iFinD MCP edb模块（2026-09-12新增），宏观经济数据库

---

## 工具能力概述

| 工具 | 能力 | 覆盖范围 |
|------|------|----------|
| `mcp__hexin-ifind-ds-edb-mcp__get_edb_data` | 宏观及行业经济指标数据查询 | 全球宏观 / 中国宏观（全国+各省市）/ 行业经济指标 / 大宗商品数据 |

### 覆盖范围详情
- **全球宏观指标**: 国际经济组织发布的全球经济数据 + 外国宏观经济指标（如美国GDP、欧盟CPI等）
- **中国宏观指标**: 全国宏观 + 各省市区域经济指标（如工业增加值、社融、PMI等）
- **行业经济指标**: 各行业主要产品的产销量、进出口等（如新能源汽车产量、光伏装机量）
- **大宗商品数据**: 上游能源、金属、化工、农产品等主要大宗商品的量价、产销、库存（如PTA周产量、铜库存）

## 输入要求 / 参数规范

- **query**: 自然语言，要素尽可能清晰详尽
- **query建议包含**:
  1. 专业指标名称术语（如"规模以上工业增加值当月同比"）
  2. 时间范围（如"202301-202506"）
  3. 国家/地区（如"中国""美国""广东省"）
  4. 数据频率（月度/季度/年度/周度）
  5. 统计类型（同比/环比/累计值/当月值）

## 输出格式说明
- 自然语言描述的结构化数据结果
- 时间序列数据按时间顺序排列
- 同比/环比等为计算值，基于原始数据派生

## 常见坑与避错指南

1. **指标名称精确性🔴**：宏观指标名称非常多且细微差别可能对应不同数据，尽量用标准术语（如"社会融资规模存量同比"vs"社会融资规模增量"）
2. **同比 vs 环比🟡**：同一指标有同比、环比、累计同比等多种口径，查询时明确
3. **数据发布滞后🟡**：宏观数据通常滞后发布（如月度数一般次月中下旬发布），最新数据可能暂未更新
4. **频率差异🟢**：GDP是季度、CPI是月度、PMI是月度，注意数据频率匹配分析需求
5. **行业指标口径🟢**：行业产销量数据口径可能随时间调整，趋势分析注意口径一致性

## 适用边界（什么情况不用）

- ❌ 股票/基金行情数据 → 用 stock-mcp / fund-mcp
- ❌ 上市公司财务 → 用 atom-ifind-stock-fundamental
- ❌ 实时新闻/政策解读 → 用 atom-ifind-news-notice 或 web_search
- ❌ 深度宏观研究 → 用deep-research skill（数据+分析+多源验证）
- ❌ 极小众/细分行业数据 → 可能不在EDB库中，需web_search补充

---

## 为什么重要

宏观经济数据是自上而下投资分析的基础——货币政策、经济周期、行业景气度都需要宏观数据支撑。iFinD EDB数据库覆盖全球+中国+行业+商品四维数据，是宏观研究和行业景气度判断的核心数据来源。
