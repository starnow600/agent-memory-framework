# atom-ifind-index-sector（iFinD指数与板块数据查询）

**层级**: Atomic
**ID**: atom-ifind-index-sector
**触发**: 需要查询指数行情、板块数据、行业/概念板块成分股等信息时
**来源**: iFinD MCP index模块（2026-09-12新增），指数与板块工具集合

---

## 工具能力概述

| 工具 | 能力 | 典型场景 |
|------|------|----------|
| `mcp__hexin-ifind-ds-index-mcp__index_data` | 指数数据指标查询：行情/技术指标 + 财务分析/估值指标 + 特殊指数指标（如债券指数到期收益率） | 大盘指数分析、指数估值 |
| `mcp__hexin-ifind-ds-index-mcp__sector_data` | 股票板块类主体数据：行情/技术指标 + 财务分析/估值指标 + 股本及股东分布指标 | 行业/概念板块分析、板块轮动判断 |
| `mcp__hexin-ifind-ds-index-mcp__index_highfreq_quotes` | 指数高频实时行情：最新快照 + 分钟K线序列 | 盘中大盘监控、实时指数数据 |

## 输入要求 / 参数规范

### index_data / sector_data
- **query**: 自然语言，包含指数/板块实体 + 查询指标 + 时间范围
- **时间序列**: 涉及时间序列请用 `YYYYMMDD-YYYYMMDD` 格式，避免相对日期
- **板块分类**: 由于板块命名有相似性，尽可能提供板块所属分类信息（如"中证行业""申万行业""概念板块"）
- **板块标的范围**: 市场分类板块、行业分类板块、概念板块等

### index_highfreq_quotes
- **symbols**: 指数列表，支持同花顺代码（如`000001.SH`）、交易所六位代码（如`000001`）、标准简称（如`上证指数`），逗号拼接，上限10个
- **indicators**: 指标列表逗号拼接，单次上限10个
- **data_mode**: `real_time`（最新快照）或 `highfreq`（分钟序列）
- **支持指标**:
  - 实时+高频共通：开盘价/最高价/最低价/均价/涨跌/涨跌幅/成交额/成交量
  - 仅实时：最新价/领先指数/总市值/上涨家数/下跌家数/涨停家数/跌停家数/停牌家数/振幅
  - 仅高频：收盘价/日内累积涨跌幅

## 输出格式说明
- index_data/sector_data: 自然语言描述的结构化指标结果
- index_highfreq_quotes: 实时行情快照或分钟序列数据

## 常见坑与避错指南

1. **指数 vs 个股代码混淆🔴**：000001既是上证指数也是平安银行，必须用`.SH`/`.SZ`后缀或全称区分（详见atom-financial-code-prefix-whitelist）
2. **板块分类不明确🟡**："半导体板块"在不同分类体系中成分股不同，查询时建议明确分类（申万/中证/概念）
3. **实时涨跌家数🟡**：上涨家数/下跌家数/涨停家数等仅实时模式支持，高频序列不返回
4. **指数估值含义🟢**：指数PE/PB是成分股加权平均，反映整体估值水平
5. **成分股个数查询🟢**：sector_data可查成分股个数，用于判断板块容量

## 适用边界（什么情况不用）

- ❌ 个股行情/基本面 → 用 stock-mcp 系列
- ❌ 基金指数 → 用 fund-mcp 模块
- ❌ 宏观经济指标 → 用 atom-ifind-macro-edb
- ❌ 历史日频数据的盘中实时查询 → 实时模式只支持日内，历史日频用index_data

---

## 为什么重要

指数和板块数据是市场状态判断的核心输入——大盘Regime判断依赖指数趋势，行业轮动分析依赖板块行情对比。iFinD MCP的index模块相比旧数据源提供了更丰富的指数财务/估值指标，以及实时涨跌家数等市场情绪指标。
