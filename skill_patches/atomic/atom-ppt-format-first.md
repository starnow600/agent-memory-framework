# Patch: ppt-format-first

## 触发条件
开始制作PPT前

## 失败根因
未确认输出格式就开工，导致：
- 做完HTML格式发现用户需要.pptx可编辑文件
- 做完.pptx发现用户只需要在线展示
- 返工浪费时间，且格式转换可能丢失样式

## 规避规则
- 制作前必须确认格式：HTML在线展示 / PPTX可编辑 / 混用方案
- 不同格式对应不同工具链，确认后再选工具
- 未确认前不可动手

## 来源案例
- 多次PPT返工经验
- 冠脉CTA PPT最终采用混用方案(create-ppt+python-pptx)
