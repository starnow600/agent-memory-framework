# Planning: 主观判断必须外部挑战（魔鬼代言人）

## 触发条件
任何主观判断场景：Review、叙事、量化分析报告、策略评估、自身能力评估

## 步骤
1. **识别判断主体**：明确这次判断是谁做出的（我/我的团队/我的假设/数据驱动）
2. **选2个外部挑战源**：从4个来源中至少选2
   - 来源A：基础概率审视（统计意义/显著性）
   - 来源B：历史数据对比（同场景过去如何）
   - 来源C：激励偏差审视（判断者是否有美化倾向）
   - 来源D：极端场景模拟（黑天鹅/边界条件）
3. **输出3级信心度**：高/中/低 + 信心度依据
4. **挑战结论单独成段**：不能藏在注释里，必须显式可见
5. **降级处理**：低信心度判断必须标注"需主人确认"

## 4选2的灵活组合
- 量化/统计判断：基础概率 + 历史数据
- 能力/系统评估：激励偏差 + 历史数据
- 风险/压力测试：极端场景 + 基础概率
- 策略/方向判断：激励偏差 + 极端场景

## 依赖关系
- 与 plan-failure-notify 互补：后者管"任务失败后通知"，本条管"判断前自检"
- 与 func-narrative-in-distill 协作：叙事提供挑战素材，魔鬼代言人提供挑战方法

## 反模式
- ❌ 跳过挑战直接给结论（"显然……"）
- ❌ 选容易的来源（如只用历史数据回避激励偏差）
- ❌ 挑战结论藏在脚注/括号里
- ❌ 全部4个来源都做（增加时长但边际收益低）
