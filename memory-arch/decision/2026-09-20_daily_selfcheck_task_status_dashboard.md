# 2026-09-20 每日自检脚本新增任务状态看板模块

## 决策类型
架构变更 / 重大任务启动

## 背景
子session和日程任务状态靠记忆+日志跟踪，10+个定时任务同时跑时容易漏。从每周探索报告的P1-3建议中产生，用户确认落地。

## 决策内容
在每日自检脚本 `daily_selfcheck_digest.py` 中新增"任务状态看板"模块：
- 当日任务完成状态（按分类分组）
- 近7天S2完整度趋势（柱状图）
- 近7天问题追踪

FS_PROBE_RULES从5个扩展到10个（新增话题追踪、Wiki编译、每周探索、周度汇报、T7周检），支持frequency字段（daily/weekday/weekly_sunday）。

## 依据
用户确认"两件事一起推进"（上下文工程+状态看板）。

## 影响范围
- 每日自检报告新增可视化状态模块
- S2文件探测覆盖范围扩大（5→10类任务）
- 9/22（周一）首次正式运行

## 验收标准
- 看板输出语法正确、数据合理
- 覆盖全部高频任务类型
- frequency字段正确区分daily/weekday/weekly_sunday
