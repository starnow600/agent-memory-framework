# 风控专家版副驾驶模式设计

**版本**: v2.2.0
**生效日期**: 2026-10-05（W13周校准）
**前身**: v2.1.0 影子测试（28天，2026-09-02~09-30）

---

## 模式定位

专家版不转正为主风控，作为**副驾驶**辅助：
- **定期复盘**：每周日深度复盘（已实现）
- **异动触发**：平日出现异常信号时，触发深度分析（待实现）

平日默认静默，不每日全量运行（节省资源+避免信息噪音）。

---

## 一、周日深度复盘（已实现）

- **触发**：每周日自动运行
- **范围**：全部持仓 + 增量扫描TOP10
- **产出**：专家版深度报告 + 与主风控对比报告
- **验证**：10/4已正常运行（第1次正式深度复盘）

## 二、异动触发式分析（待实现，W14）

### 触发条件

满足任一即触发专家版深度分析：

| 触发源 | 条件 | 级别 |
|--------|------|------|
| **M1止损** | 新增持仓破Hybrid止损线 | 🔴 必触发 |
| **M6分级恶化** | 持仓从🟢→🟡或🟡→🟠 | 🟠 必触发 |
| **单日跌幅** | 持仓单日跌幅≥8% | 🔴 必触发 |
| **大盘异动** | HS300单日涨跌幅≥3% | 🟡 可选触发 |
| **行业剧变** | 持仓所属行业单日涨跌幅≥5% | 🟡 可选触发 |

### 触发方式

- 在 `daily_risk_check.py` 主风控完成后，增加触发检测钩子
- 命中触发条件 → 调用 `daily_risk_expert.py` 的深度分析模块（只分析触发标的，不全量）
- 未命中 → 静默，不调用专家版

### 输出模式

- 触发时生成**异动专题分析报告**（聚焦触发原因、后续走势判断、操作建议）
- 通过 notify 推送（不打扰用户的正常流，但保证可达）
- 报告归档到 `expert_shadow/` 目录

### 技术实现

- 专家版拆成模块：`expert_core.py`（深度分析逻辑）+ `daily_risk_expert.py`（入口脚本）
- 主风控直接 import expert_core 的函数，不用重新初始化全套环境
- 触发条件配置化，存在 `config/expert_triggers.json`

## 四、与主风控的关系

| 维度 | 主风控（daily_risk_check） | 专家版（副驾驶） |
|------|---------------------------|-----------------|
| 运行频率 | 每日 | 周日 + 异动触发 |
| 输出 | 完整风控报告（M1-M7） | 深度分析（触发标的） |
| 决策权重 | 主要决策依据 | 辅助参考 |
| 数据源 | 三级兜底 | 同主风控 + 额外深度指标 |
| 止损判断 | 执行 | 不执行，只分析 |
