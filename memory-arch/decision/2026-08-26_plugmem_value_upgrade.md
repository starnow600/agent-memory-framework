# 决策记录：PlugMem价值化升级（方案B→方案C进化路径）

**日期**：2026-08-26
**类型**：架构变更 / 项目启动
**状态**：Phase 0完成，待进入Phase 1

## 背景
JitRL论文（ICML 2026 Spotlight）提出"测试时强化学习"思想，与现有PlugMem记忆系统有很强的双向互补性。经过深度评估后，决定采纳方案B（中度融合：价值评估+质量闭环），并预留向方案C（完整JitRL闭环）进化的路径。

## 决策内容
1. **采纳方案B（中度融合）**作为当前目标，包含：ValueEstimator、MemoryQualityManager、上下文感知检索、反馈闭环
2. **分4个Phase渐进实施**，每阶段有独立验收节点，不达标不进入下一阶段
3. **从Phase 0开始同步采集轨迹数据**，为方案C验证做准备，不等到B做完才开始
4. **Phase 3结束后设决策门（Go/No-Go）**，基于数据判断是否值得投入方案C

## 理由
- 方案B收益成本比最优：2-3周工作量，预期Top-1准确率提升20-30%
- 与现有PlugMem架构兼容性最好，不改变核心数据结构和检索范式
- 解决了当前最核心的短板：静态排序+无反馈闭环
- JitRL最有价值的思想（动态价值估计、优势排序、反馈闭环）在方案B中已经吸收
- 方案C虽然理论收益最大，但技术风险高、周期长，需要先验证核心假设

## 实施路径
- Phase 0（0.5周）：基线评估 + 数据结构改造 + 轨迹日志启动 ✅ 完成
- Phase 1（1周）：价值重排序（ValueEstimator V1）
- Phase 2（1.5周）：质量闭环 + 上下文感知（完整方案B）
- 稳定观察期（2周）：收集真实数据
- Phase 3（1.5周）：轨迹采集 + 状态匹配验证 + C可行性预评估
- 决策门：Go/No-Go for 方案C
