**背景**：B方案Phase 2完成后，对照JitRL原论文系统性评估差距。B方案是中间版本，最终向C方案（完整JitRL闭环）进化，本文档记录所有差异作为后续改造方向。
**论文**：JitRL: Just-In-Time Reinforcement Learning, arXiv:2601.18510

## 二、四大差距维度（进化优先级从高到低）

### 差距1：价值估计方式（对齐度40%）— 最关键差距

**论文**：Q(s,a) = **状态依赖**的动作价值。给定当前状态s，从记忆库检索相似轨迹，聚合计算每个动作的期望回报。同一动作在不同状态下价值完全不同。

**B方案**：value_score = **全局静态**评分（5维度加权：频率+时效性+置信度+来源+反馈）。不管理什么查询场景，同一条记忆的value_score都一样。

**进化方向**：
- Phase 3先做轨迹采集和状态匹配验证（B+过渡）
- C方案实现真正的Q(s,m) = 给定查询状态s，记忆m的期望价值
- 需要构建"查询上下文→记忆价值"的动态映射

**贡献估计**：占论文总提升的30-40%

---

### 差距2：反馈信号密度（对齐度30%）

**论文**：
- 每个episode有多个step，每个step都有LLM评分生成reward
- 50个episode → 几百条带标签的(state, action, reward)数据
- 有折扣回报G_t = Σγ^{u-t}r_u，做信用分配

**B方案**：
- 冷启动0真实反馈，value_score全靠启发式权重
- 反馈只有"引用即反馈"（隐式正反馈）和零星的显式评分
- 无信用分配机制，反馈只影响整条记忆，不区分上下文

**进化方向**：
- 轨迹级别反馈（查询→检索→结果→是否有用，完整链路标注）
- 延迟反馈折扣（Phase 2已部分实现）
- LLM自动评估记忆对查询的贡献度（类似论文的Reflective Step-wise Rewards）

**贡献估计**：占论文总提升的10-20%，但是状态匹配的前置条件

---

### 差距3：探索机制（对齐度0%）

**论文**：UCB风格探索奖励。记忆中没有的新动作，以概率λ赋予乐观值Q̂ = V̂ + α/|N(s)|，鼓励探索未知动作。

**B方案**：完全保守——正向优势策略"只升不降"，新记忆/低价值记忆永远排在底下，不会被"尝试性提到前面"。

**为什么B方案故意不做探索**：
记忆检索是"离线优化"而非"在线决策"。把不确定的记忆提到前面会直接损害用户体验。

**进化方向（C方案才考虑）**：
- 新秀保护机制：新创建的记忆给"探索期"临时提升排名获取曝光
- 置信度低但潜在价值高的记忆，在特定查询中小幅提升测试
- 探索成本监控：如果Top-1准确率下降超过阈值自动回退

**贡献估计**：占论文总提升的5-10%，但风险较高

---

### 差距4：优势函数实现细节（对齐度90%）— 基本对齐

已对齐：
- ✅ 优势函数 A = Q - V̂
- ✅ 正向优势（B方案更保守，只升不降；论文对称升降）
- ✅ β控制强度（KL约束思想）
- ✅ 优势归一化
- ✅ 冷启动保护（检索不到/区分度不足时退化为基础模型）

仍有差异：
- 论文负优势会降低logit，B方案只升不降
- 论文β=1（WebArena），B方案β=0.2（保守很多）
- 价值基线V̂：B方案8/26刚从"当批均值"修正为"全局均值"

**进化方向**：
- 反馈数据充足后评估是否加入"轻量下压"
- β参数随反馈积累渐进增大（类似Jericho的episode_weight机制）

**贡献估计**：剩余10%优化空间，收益递减

## 三、进化路线图

```
B方案(当前)          B+过渡(Phase 3)          C方案(完整闭环)
    │                    │                          │
    ├ 静态value_score    ├ 轨迹采集就绪             ├ 状态依赖Q(s,m)
    ├ 正向优势重排序     ├ 上下文状态匹配验证       ├ 完整探索机制
    ├ 上下文(平票决胜)   ├ 动态价值初版             ├ LLM反射式奖励评估
    └ 基础反馈收集       └ 轨迹级别反馈             └ 对称优势调整(升降皆可)
                          │                          │
                      对齐度~65%                 对齐度~90%+
                    预期Top-1 +20-25pp         预期Top-1 +30pp+
```

## 四、观察期重点监控指标

1. **EMA价值分波动幅度**：单节点value_score单周波动>0.2说明EMA机制不稳定
2. **马太效应**：新创建节点的排名变化曲线，是否永远垫底
3. **反馈积累速度**：每周有效反馈条数
4. **上下文感知介入频率与准确率**

## 五、决策门（Gate C）条件

从B+进化到C方案需同时满足：
1. B+方案稳态Top-1提升≥20pp
2. 轨迹数据量≥200条有效查询轨迹
3. 状态匹配验证显示相似查询的记忆价值分布差异显著
4. 工程资源评估：C方案2-3个月工作量可接受
