# 2026-09-03 风控专家版v2.0分级预警+深度分析升级

**决策日期**：2026-09-03
**决策类型**：架构变更 / 重大任务启动
**触发背景**：长川科技触发Hybrid止损后，deep_research产出的深度分析报告（2.9万字/6维度/5张图表）颗粒度远超当前风控水平，主人提出"为什么等落地再加，现在一起验证"，推动影子测试期内就升级专家版。

---

## 一、决策内容

### 升级前状态
- 专家版风控：2095行，5个结构化模块（M1止损/M2仓位/M3 Regime/M4信号质量/M5纪律）
- 输出：纯规则判断的文字报告，不调LLM、不搜新闻
- 影子测试期：9/1~9/28，对比基准版核心判断一致性
- 问题：持仓分析只有"触发/安全"二分类+Hybrid线位置，缺少分级预警、概率判断、盈亏比等决策辅助信息

### 升级后状态（v2.0）
- **新增M6分级预警模块**，三档自动判定：

| 档位 | 触发条件 | 输出粒度 | 预计耗时 |
|------|---------|---------|---------|
| 🟢 安全 | Hybrid线上>5% + MA20线上+2% | 简版：现价/位置/一句话 | <1分钟/只 |
| 🟡 关注 | 5%>Hybrid线上>0 或 MA20濒临(±1%) | 标准版：技术面+资金面+支撑位 | 2-3分钟/只 |
| 🟧 警戒 | Hybrid跌破 或 单日跌>5% 或 MA20跌破>2% | 深度版：6维度全分析+盈亏比+图表 | 10-15分钟/只 |

- **橙色档深度分析**：技术面/基本面/资金面/历史复盘/风险评估/操作建议 6维度 + 关键图表
- **技术方案**：
  - 超时拉到3600秒（保险上限）
  - 先输出分级判断+绿/黄档结果（保证基准对比数据不丢）
  - 橙色档继续深挖，挖完补全报告
  - M1-M5完全未动，对比口径不受影响

### 修复的问题（v2.0.1）
- **价格口径不一致bug**：深度分析模块用实时搜索价 vs 基准版iFinD收盘价，差0.47%可能导致止损判断反转
- **修复方式**：prompt强制约束+上下文标注"iFinD收盘价为权威基准，禁止以搜索结果中的实时行情价替换"

## 二、决策依据

1. **影子测试的核心价值是迭代**：并行期间就是用来发现问题、迭代能力的，等转正再加等于浪费4周对比窗口。主人点破的逻辑——"为什么现在不加，一起验证呢"
2. **分级预警是增量逻辑**：不影响M1-M5核心判断（触发/不触发），输出更多信息，对比口径不变
3. **有现成模板**：长川深度分析报告可以直接当橙色档的标杆
4. **风险可控**：影子测试期，改动即使有问题也不影响实际决策

## 五、风险与注意事项

1. **耗时风险**：两只持仓同时橙色可能30分钟+，19:00触发可能19:30后才出结果。已设3600秒超时
2. **iFinD token消耗**：深度分析增加接口调用量，可能导致日配额超限（9/3下午已发生）
3. **数据一致性**：深度分析模块必须严格使用iFinD收盘价为基准，禁止自行搜索实时价（已加prompt强制约束）
4. **影子测试对比口径**：M1-M5完全未动，核心判断对比不受影响；增量模块（M6）不参与对比
