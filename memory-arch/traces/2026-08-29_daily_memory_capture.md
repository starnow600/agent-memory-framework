## 四、新学习/洞察

### 1. 机构持股数据的时效性判断
- 半年报披露的机构持股数据是**期末数据**（如6月30日），披露日（如8月27日）不代表数据日期
- 8月底看到Q2机构减持属于**滞后信号**，股价大概率已在Q2末-Q3初的下跌中price in
- 教训：看到机构持股变化时，**先确认数据截止日**，不要把披露日当成数据日

### 2. 滞后信号vs新信号的区分框架
- 新信号 = 数据日期在最近2-4周内，市场尚未充分消化
- 滞后信号 = 数据日期超过1个月，对应时间段的股价波动已反映该信息
- 滞后信号用于**验证历史逻辑**，不用于**预测未来走势**
