## 五、iFinD MCP根因修正 ✅

### 真相

不是MCP挂了，是适配器解析bug：
- `_parse_inner_answer` 函数期望 `data` 是JSON字符串
- 但MCP插件返回的 `data` 已经是dict对象
- `json.loads(dict)` 抛异常 → 返回None → 上层认为空数据

### 修复

- 加dict类型判断，是dict直接用，字符串才json.loads
- 修复时间：2026-10-04
- 单元测试：通过

### 影响修正

- W13快览已追加"根因修正"章节（保留原始分析轨迹+补充真相）
- 此前"连续10交易日全不可用"结论修正为"连续10交易日适配器解析失败"
- coarse_screen是被动降级的判断部分修正——降级是真的，但触发原因是自bug

### 教训

1. 数据源故障先排查自身代码（用户指出的方向正确）
2. "返回空"≠"服务空"，解析层也可能出问题
3. init成功≠数据可用≠解析成功
